Can I use Nexora with existing tools?+

This static concept demonstrates workflow patterns; the production integration layer would be configured by the deploying organization.

Is the demo connected to a live AI model?+

No. All chatbot replies and simulations are deterministic local examples, so they work without API keys and never pretend to submit data.

Can this be deployed to GitHub Pages?+

Yes. The site uses relative paths and no server-side code, so it can be hosted directly from a repository Pages branch or folder.
